# Project Context

**Project:** Automated Liquidity & Interest Rate Risk Monitoring Platform
**Goal:** Production-quality portfolio project for JPMorgan-style Risk Analyst roles.

## Working rules
1. Think of the project as a whole; build step by step with the big picture in mind.
2. Code must not break as the project grows (config over hardcoding, schemas, tests).
3. Every line must be understood and explainable by the author.
4. Regulatory correctness over polish; all simplifications labelled.

## Architecture
Raw -> Validated (+ quarantine) -> Metrics -> Reporting
